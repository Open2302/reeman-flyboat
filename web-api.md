# Интеграция с Web API робота

> Рабочие заметки: данные для интерфейса, статусы робота и примеры POST-запросов.

## 1. Статус бар

### 1.1 Батарея

### Get Запрос:

```javascript
fetch('http://10.6.20.95/reeman/base_encode', {
    method: 'GET',
    headers: {
        'Content-Type': 'application/json'
    }
})
```

### Предположительный ответ:

```javascript
{"battery":100,"chargeFlag":2,"emergencyButton":1}
```

- **Поле API:** `Battery` отображение уровня заряда батареи робота.
- **Индикатор зарядки:** если `Charge flag == 2`, робот заряжается от станции — рядом с батареей можно отображать значок молнии ⚡.

### 1.2 Место / цель движения

### GET Запрос:

``` javascript
fetch('http://10.6.20.95/reeman/nav_status', {
    method: 'GET',
    headers: {
        'Content-Type': 'application/json'
    }
})
```

### Предположительный ответ:

```javascript 
{"res":3,"reason":0,"goal":"Зарядка","dist":0,"mileage":0.3}
```

- **Поле API:** `goal`
- **Назначение:** точка, в которой находится робот, либо точка, к которой он движется.

### 1.3 Статус движения

### GET Запрос:

``` javascript
fetch('http://10.6.20.95/reeman/speed', {
    method: 'GET',
    headers: {
        'Content-Type': 'application/json'
    }
})
```

### Предположительный ответ:

``` javascript
{"vx":0,"vth":3.0234013993166225e-7}
```

- **Поле API:** `vx`
- **Описание:** скорость робота в метрах в секунду (`м/с`).

### 1.4 Статус маршрута

- **Состояние:** пока не определено.

### 1.5. Аварийные кнопки

### GET Запрос:

```javascript
fetch('http://10.6.20.95/reeman/base_encode', {
    method: 'GET',
    headers: {
        'Content-Type': 'application/json'
    }
})
```

### Предположительный ответ:

```javascript
{"battery":100,"chargeFlag":2,"emergencyButton":1}
```

**Поле API**: `emergency button`.

- `0` — нажата какая-либо кнопка аварийной остановки.
- `1` — кнопка аварийной остановки опущена.

## 2. Main Window

### 2.1 Отправка на точку

### POST Запрос:

```javascript
fetch('http://10.6.20.95/cmd/nav_name', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ "point": "Место назначения" })
})
```

- **Поле API**: `"point": "Место назначения"`
- **Назначение:** Вызов в конкретную точку

## 2.2. Поднятие лифта

## 3. Сводная таблица полей API

| Поле | Назначение / интерпретация |
|---|---|
| `Battery` | Уровень заряда батареи |
| `Charge flag` | Значение `2` означает зарядку от станции |
| `Goal` | Текущая точка робота или цель движения |
| `vx` | Скорость робота, м/с |
| `emergency button` | `0` — аварийная кнопка нажата; `1` — опущена |
